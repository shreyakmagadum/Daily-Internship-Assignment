# Logistic Regression Visualizer

## Project Description

This project is an interactive Streamlit application that explains **Logistic Regression step-by-step**.
It helps users understand classification, sigmoid function, decision boundaries, and model training visually.


## Objectives

* Understand classification vs regression
* Learn sigmoid function behavior
* Visualize decision boundary
* Implement logistic regression from scratch
* Compare with sklearn model


## Features

*  Data visualization
*  Linear model limitation demo
*  Sigmoid function graph
*  Logistic curve visualization
*  Gradient descent training
*  Decision boundary display
*  Prediction & accuracy
*  Comparison with sklearn


## Tech Stack

* Python
* NumPy
* Matplotlib
* Streamlit
* Scikit-learn


## How to Run

pip install -r requirements.txt
streamlit run app.py
